# Data dictionary (Part E)

One row per column in your output file, in the order the columns appear.
Include the columns PsychoPy adds on its own; you may group families of them
(for example, every `*.started` column) in one row if you say what the family
covers and list its members.

**Source** is one of: trial list, startup dialog, your code (name the
component), PsychoPy automatic.

**Rows** says which rows carry a value: trials only, practice only,
experimental only, the first row only, every row.

If a column name appears more than once, give each copy its own row and say
how a program reading the file will see them.
